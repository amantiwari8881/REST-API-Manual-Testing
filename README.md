# REST API Manual Testing Project

## Project Overview
This project demonstrates manual API testing using Postman. The project uses the JSONPlaceholder REST API to test different HTTP methods and verify API responses.

## Tools & Technologies
- Postman
- REST API
- JSON
- Microsoft Excel
- GitHub

## API Testing Coverage

| HTTP Method | Test Cases |
|---|---:|
| GET | 15 |
| POST | 15 |
| PUT | 15 |
| PATCH | 15 |
| DELETE | 15 |
| **Total** | **75** |

## Project Structure
- `Excel-Reports/` – Contains the Excel execution report.
- `Postman-Collection/` – Contains the exported Postman collection.
- `README.md` – Project documentation.

## Test Execution
- Created and executed API requests manually in Postman.
- Verified HTTP status codes and response bodies.
- Documented expected and actual results in Excel.
- Covered positive, negative, and edge-case scenarios.

## API Used
JSONPlaceholder: https://jsonplaceholder.typicode.com

## Important Note
JSONPlaceholder is a fake online REST API for testing and prototyping. POST, PUT, PATCH and DELETE operations do not persistently modify server data.
